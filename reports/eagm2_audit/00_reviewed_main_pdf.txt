1    Introduction                                                rate project; the overlap and additional algorithmic ev-
A robot command is not necessarily the actuator in-              idence must be documented before submission of this
put that causes the next observed transition. Control            manuscript.
software may accumulate target positions, ﬁlter incom-
ing commands, buﬀer actions, or limit command rates.
Some of this execution state is observable; other param-
eters and memories may be unavailable to a deployed
predictor. This interface matters when a world model is
diﬀerentiated to improve a policy, rather than used only
to predict a state.
   A low prediction error does not constrain all local
derivatives. Moreover, even an accurate policy gradi-
ent is deﬁned for a particular objective and starting-
state distribution. The optimizer then transforms that
gradient into an update. Our central question is con-
sequently restricted: can command-structured model-
ing and simulator-derived gradient supervision improve
physical policy returns under partially observed execu-
tion dynamics, and where does this approach fail?

Value and gradient propagation. VaGraM weights

action attribution [6]. This overlaps with the broad moti-
vation of execution consistency. EAGM’s proposed dis-
tinction is supervised gradient quality under partially
unknown execution dynamics, not the discovery that ex-
ecution interfaces matter.
   SuperMimic uses a diﬀerentiable learned model and
short imagined backpropagation for humanoid track-
ing [3]. Its controller inputs and code-level actuator
assumptions have not yet been fully audited here; we
therefore make no claim that it lacks execution informa-
tion and no numerical comparison to its reported perfor-
mance.

Rejected extensions. History alone can improve
some dynamics prediction metrics without a match-
ing return improvement. HistC, which adds observed
control-state history, did not show a reliable independent
temporal-structure beneﬁt against capacity and ordering
controls. Path-Dir did not consistently improve over Dir-
Random; only two of ﬁve seed diﬀerences were positive.
Reduced policy learning rates removed parameter sat-
uration without producing a reliable performance gain.
These are reasons to retain a smaller supported method,
not modules to be repackaged as contributions.

Reach protocol correction. The initial reaching ex-
periments used a learned FK surrogate for both imagined
reward and the reported physical ﬁnite-diﬀerence objec-
tive. A surrogate-path parity check could not establish
agreement with the actual end-eﬀector objective. The
corrected experiment regenerated direction labels using
true MuJoCo geometry and retrained Dir. On seed20,
Dir’s mean true return was approximately −0.015714,
versus Base −0.015449; Dir’s change from initialization
was negative. This is a failed transfer experiment, not
evidence of task generalization.

Geometry decomposition. The geometry audit
measured position RMSE around 2.24 cm, relative Ja-
cobian error around 30%, and Jacobian cosine 0.964 on
its held-out trajectory-state subset. These metrics use a
diﬀerent state distribution from the earlier FK-ﬁt accep-
tance test and must not be substituted for it. Replacing
the position residual while retaining the FK Jacobian
improved state-level reward-gradient cosine from 0.441
to 0.957. Replacing the Jacobian alone did not help.
Thus, a large relative derivative error did not imply a
comparably large directional error.
   Complete true-reward derivative replacement still
left the mean policy-gradient cosine negative (about
−0.116). It partially improved the 50-update physi-
cal return but did not restore the initial-policy return.
This distinguishes state-level reward geometry from full
policy-gradient propagation and motivates the next anal-
ysis; it does not support a Geometry-aware EAGM
method.
